# /scaffold-feature <이름>

$ARGUMENTS 기능을 **이 레포의 기존 관례에 맞춰** 스캐폴드한다. 스택(웹·앱·Python·.NET 등) 무관.

절차:
1. 이 레포에서 **가장 비슷한 기존 기능/모듈을 하나 찾아** 참조 패턴을 파악한다:
   폴더 구조, 파일 네이밍, 등록/라우팅 방식, 테스트 위치, 진입점.
2. 그 패턴을 그대로 따라 새 기능의 뼈대를 만든다. 새 관례를 임의로 도입하지 않는다.
3. 필요한 등록(라우트/DI/모듈 인덱스/내비게이션 등)을 이 레포 방식대로 연결한다.
4. 색·문자열·설정은 하드코딩하지 말고 이 레포의 토큰/리소스/설정을 참조한다.
5. 빌드/실행으로 컴파일·구동을 확인한다. 테스트 관례가 있으면 테스트 뼈대도 만든다.

원칙: **기존 코드를 닮게.** 이 레포가 이미 하는 방식이 항상 우선한다.
