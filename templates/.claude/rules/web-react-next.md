# Next.js / React 규칙 (웹 레포용)

Next.js(App Router) / React 웹 프론트엔드 레포에서만 활성화.
※ 표준 원본: claude-code-standard v0.7 — 이 파일은 레포에서 직접 수정하지 말 것(표준 레포 PR로).

## App Router
- **서버 컴포넌트 기본**, 상호작용이 필요한 곳에만 `"use client"`.
- 데이터 패칭은 서버 컴포넌트/서버 액션에서. 클라이언트에 비밀을 노출하지 않는다.
- 라우팅은 `app/` 디렉토리 규칙(`page.tsx`, `layout.tsx`, `loading.tsx`, `error.tsx`)을 따른다.

## 컴포넌트
- 서버/클라이언트 경계를 명확히 나눈다. 클라이언트 트리를 필요 이상으로 키우지 않는다.
- 반복 UI는 컴포넌트/디자인 토큰으로 추출한다.
- 상태는 가능한 한 지역화한다. 전역 상태는 꼭 필요한 것만.

## 스타일 · 접근성
- 색/간격은 디자인 토큰(CSS 변수/테마)을 참조한다.
- 접근성: 시맨틱 태그, 키보드 포커스, 명도 대비를 기본으로 지킨다.

## 빌드 · 검증
- 빌드: `npm run build`(또는 프로젝트 매니저). 린트/타입체크를 통과시킨다.
- 변경 후 실제로 렌더링/동작을 확인한다.

## 콘텐츠 퍼블리싱(선택)
- 블로그/SEO 변환 같은 개인용 출력 포맷은 **팀 표준이 아니라 개인 output-style**로 둔다.
