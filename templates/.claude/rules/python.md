# Python 규칙

Python 레포(FastAPI 등 웹 백엔드·CLI·스크립트·데이터/ML)에서 활성화.
※ 표준 원본: claude-code-standard v0.9 — 이 파일은 레포에서 직접 수정하지 말 것(표준 레포 PR로).

## 프로젝트 · 의존성
- 의존성/도구는 이 레포가 쓰는 매니저를 따른다(`uv`, `poetry`, `pip`+`requirements.txt` 등). 임의로 바꾸지 않는다.
- 가상환경 안에서 실행한다. 전역 설치를 강요하지 않는다.
- 실행/테스트/린트 명령은 CLAUDE.md에 정확히 기입(예: `pytest`, `ruff check`, `python -m <pkg>`).

## 스타일
- **PEP 8** + 이 레포의 포매터(`ruff`/`black`)를 따른다. 수동 정렬보다 포매터에 맡긴다.
- **타입 힌트**를 쓴다. 공개 함수/모듈 경계에는 특히.
- 함수는 작게, 부작용은 명확하게. 전역 상태를 피한다.

## 견고성
- 예외는 구체적으로 잡는다(`except Exception` 남발 금지). 삼켜서 조용히 넘기지 않는다.
- 경로/파일/네트워크는 리소스 관리(`with`)로 안전하게.
- 외부 입력은 검증한다.

## 테스트
- `pytest` 등으로 변경을 검증한다. 새 기능엔 테스트를 곁들인다.
- "된다"고 말하기 전에 실제로 실행한다.

## 보안
- 비밀은 코드에 하드코딩하지 말고 환경변수/시크릿 매니저로.
- 신뢰할 수 없는 입력으로 `eval`/`pickle`/셸 문자열 조립을 하지 않는다.
