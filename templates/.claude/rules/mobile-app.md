# 모바일 · 앱 규칙

모바일/데스크톱 앱 레포(iOS·Android·Flutter·React Native·Electron 등)에서 활성화.
※ 프레임워크가 다양하므로, 아래 공통 원칙 + 해당 레포의 실제 관례를 우선한다.
※ 표준 원본: claude-code-standard v0.9 — 이 파일은 레포에서 직접 수정하지 말 것(표준 레포 PR로).

## 아키텍처
- 이 레포의 상태관리/아키텍처 패턴(MVVM, MVI, Redux, Provider, Bloc 등)을 **따른다**. 새 패턴을 임의 도입하지 않는다.
- UI와 비즈니스 로직을 분리한다. 화면 코드에 네트워크/DB 로직을 섞지 않는다.
- 화면 간 이동은 이 레포의 라우팅/내비게이션 규약을 쓴다.

## UI
- 색·간격·타이포는 하드코딩하지 말고 **디자인 토큰/테마**를 참조한다.
- 반복 UI는 컴포넌트/위젯으로 추출한다.
- 다양한 화면 크기·방향·안전영역(safe area)을 고려한다.

## 비동기 · 성능
- 메인/UI 스레드를 막지 않는다. I/O·네트워크는 비동기로.
- 리스트는 가상화/지연 렌더링을 유지한다. 큰 이미지는 적절히 리사이즈.

## 플랫폼 · 검증
- 빌드/실행 명령은 CLAUDE.md에 정확히 기입(예: `flutter run`, `npm run ios`, Xcode/Gradle).
- 변경 후 실제 시뮬레이터/기기 또는 QA 스킬로 동작을 확인한다.
- 권한(카메라·위치 등)·비밀 키는 코드에 하드코딩하지 않는다.
